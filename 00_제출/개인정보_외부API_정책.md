# 개인정보 및 외부 API 처리 정책 — 페이체크

작성 2026-08-28 · 이 문서의 모든 서술은 코드 실물과 일치한다 (근거 경로 병기).

## 1. 무엇을 저장하는가 — 아무것도

- 서버에 DB·세션 저장소가 없다. 입력은 요청 처리 후 사라진다.
- 상담 기록도 서버에 남지 않는다 — 상담사가 승인한 뒤 브라우저에서 파일(.md)로
  내려받아 본인이 보관한다 (`lib/consult.ts`). "저장된다"고 말하지 않기 위한 경로다.
- 판정(금액·기한 계산)은 **브라우저 안에서** 순수 함수로 실행된다 — 서버로도 가지 않는다.
- "저장하지 않음"과 "외부 처리 가능성"은 다른 문장이므로 화면에 나눠 고지한다
  (`app/_agent.tsx` 입력 처리 고지, 속성 패널 하단).

## 2. 무엇이 외부로 가는가 — 두 경우뿐

| 경우 | 나가는 것 | 받는 곳 |
|---|---|---|
| Agent 실행 | 자유 발화 원문 | 설정된 모델 제공자 |
| 모국어 번역 | 조립된 답변 문장 | 설정된 모델 제공자 |

- 제공자: 배포 `ANTHROPIC_API_KEY`(Anthropic API) / 로컬·내부망 `OLLAMA_URL`(자체 서버).
  둘 다 없으면 전송 자체가 없고 화면은 "미연결"을 표시한다.
- 외부 제공자의 보존·학습 정책은 해당 약관을 따른다 — 우리가 통제하지 못하는
  부분을 통제한다고 쓰지 않는다.

## 3. 개인정보 차단 (전송 전)

- 주민·외국인등록번호, 휴대전화, 계좌번호 꼴은 서버가 **제공자 호출 전에 400으로
  거부**한다. 거부 메시지에 걸린 값을 되돌려주지 않는다. (`lib/ai/guard.ts`,
  테스트 `guard.test.ts` — 검증 순서상 PII 검사가 제공자 확인보다 앞이라
  키 없는 배포에서도 동일하게 차단)
- 사용자 화면은 애초에 이름·연락처·신원번호를 **입력받지 않는다** (5칸: 국적·비자·
  입사일·출국일·월급).
- 저장소 자체도 매 CI에서 PII 패턴 스캔을 통과해야 한다 (`scripts/scan.mjs`, 오류 0).

## 4. 운영 보호

- 분당 20회/IP 요청 제한 — 서버리스 특성상 **인스턴스별 카운트**라는 한계를
  숨기지 않는다 (실서비스 전환 시 외부 저장소 기반 필요, `lib/ai/guard.ts` 주석).
- 모든 API 응답에 `x-request-id` 헤더. 입력 2,000자·답변 120줄 상한.
- 모델 호출은 토큰·시간·차단 사유까지 감사 원장에 기록된다 (화면 「감사 기록」).

## 5. 이 결과의 성격

법률 자문이 아니라 **서류 대조 결과**다. 확정 금액과 추정 범위를 분리해 말하고,
추정은 "기관 확인 후 확정"임을 문장 틀이 강제한다 (`lib/narrate.ts`).
