# 배포 체크리스트 — 사람 손 순서 (Vercel)

목표: 공개 URL 확보 + 9/7 11:00~9/11 23:59 무중단. **URL 없으면 결격이다.**

## A. 최초 배포 (약 20분)

1. `vercel.com` 로그인 (GitHub 계정) → **Add New → Project**
2. 저장소 `LSB-afk/2026-DACON-Fin-AI-Challenge` import
3. **Root Directory = `service`** ← 이걸 빼먹으면 빌드가 저장소 루트에서 돌다 실패한다
4. Environment Variables에 추가:
   - `ANTHROPIC_API_KEY` = (콘솔에서 발급한 키) — 3단 번역·Agent가 이 키로 산다
   - `ANTHROPIC_MODEL`은 생략 가능 (기본 claude-sonnet-5)
   - `OLLAMA_URL`은 **넣지 않는다** — 서버리스에서 localhost는 없다
5. Deploy → 완료 후 URL 복사
6. **시크릿 창**에서 URL 열어 확인: 로그인 벽 없음 · 「사용자 화면」 렌더 ·
   판정 실행 동작 · (키 넣었으면) 답변 탭 번역 1회
7. URL을 기획서 ①과 기능명세서 1에 기입, 데이콘 제출 폼에도

## B. 배포 후 스모크 (기계)

```bash
cd service && node scripts/smoke.mjs https://<배포도메인>
```
- 검사: GET / 200 + "페이체크" 문자열 · GET /api/narrate 가 provider JSON 응답
- 심사 기간(9/7~9/11) **하루 1회** 실행하고 결과를 기록해 둔다 (하루 2분)

## C. 문제 시 롤백

- Vercel 대시보드 → Deployments → 직전 성공 배포 → **Promote to Production**
- 원인 불명이면 main을 직전 태그로 되돌리지 말고(이력 보존), 핫픽스 커밋으로 전진

## D. 주의

- 키는 이 저장소 어디에도 커밋하지 않는다 (`.env*` gitignore + scan이 감시)
- 심사 기간에는 main 푸시를 멈춘다 — 자동 재배포가 무중단 조건을 위협한다
  (부득이하면 Vercel에서 자동 배포를 끄고 수동 Promote)
