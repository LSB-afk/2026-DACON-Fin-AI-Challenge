# WCAG 2.2 성공 기준(Success Criteria) 체크리스트

- 출처: W3C Recommendation, WCAG 2.2 (2024-12-12 판) — https://www.w3.org/TR/2024/REC-WCAG22-20241212/
- 총 86개 성공 기준 (A 31개 / AA 24개 / AAA 31개). WCAG 2.1 대비 9개 신설, 1개 제거(4.1.1 Parsing).
- **2.2 신설 기준**은 `🆕` 표시: 2.4.11, 2.4.12, 2.4.13, 2.5.7, 2.5.8, 3.2.6, 3.3.7, 3.3.8, 3.3.9
- 사용법: 각 행의 `[ ]`를 체크하며 점검. 등급 A → AA → AAA 순으로 누적 적합.
