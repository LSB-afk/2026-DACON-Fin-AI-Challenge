# 중앙 입체 사무실 — 구현·검증 결과

2026-09-05 / 로컬 변경. 커밋·푸시·배포는 수행하지 않았습니다.

## 확인 방법

[로컬 서버](http://localhost:3000) → **바로 콘솔로** → **AI 상담 진행**.
중앙 로비에서 상담을 열고 실행합니다. 전체 보기, 중앙 로비, 현재 업무, 확대·축소, 드래그, 미니맵, 고객·담당자·문서 선택과 추적을 지원합니다.

## 구현 결과

- 기존 80×45 도시 지도를 104×68 중앙 사무실로 교체했습니다. 면적은 약 1.96배이며 6개 권역에 24개 업무·지원 공간을 배치했습니다.
- 일관된 아이소메트릭 투영에 벽 두께·문·가구 높이·그림자·앞뒤 가림을 적용했습니다. 서가, 회의 테이블, 그래프 보드, 서버, 라운지가 부서별 역할을 드러냅니다.
- 고객은 중앙 상담 공간에 머물고 요청 문서가 문과 복도를 통해 이동합니다. 실제 동시 요청, 선행 결과 대기, 누락 정보의 판정실→상담석 복귀, 결과 검토 전달을 표시합니다.
- 실행·상담 ID와 입력 버전으로 늦은 응답을 차단합니다. 수정값·기준일·승인값·적용값을 통일하고 승인, 결과 적용, 기록 완료를 구분했습니다. 선택하지 않은 번역은 완료 분모에서 제외합니다.
- 모바일은 축소 지도와 읽기 쉬운 상태·입력·승인 화면을 제공합니다. 키보드, reduced-motion, 정지 및 숨김 상태 렌더 중단을 지원합니다.

## 실제 AI와 테스트 응답의 구분

- **실제 로컬 연결**: `ollama:gemma4:latest`. 가상의 상담 문장으로 브라우저 버튼을 직접 조작했습니다. 두 요청 실행 상태를 관측하고, 약 35.5초에 근거가 있는 추출값·판정·승인 가능 상태를 확인했습니다. 승인과 적용 후 약 35.8초에 `100%`, `결과 적용·기록 완료`, 이력 1건을 확인했습니다. 브라우저 오류 0.
- **실제 API 이벤트**: 별도 NDJSON 검사에서 routing/extract 시작, routing 완료 24,440ms, extract 완료 43,450ms와 최종 정상 응답을 각각 관측했습니다. 이 시간은 위 브라우저 실행과 다른 실행의 수치입니다.
- **제어된 테스트 응답**: 22개 브라우저 회귀는 테스트에서 응답 순서를 제어하는 fixture입니다. 앱에 가짜 업무 타이머를 넣지 않았습니다. 번역 계약은 기존 실제 코드의 단위 테스트로도 검증했습니다.

## 성능 측정과 제한

- Chrome 152 headless, macOS, 1440×900, DPR 1. 정지 화면 701.7ms 동안 추가 렌더 0회. 누적 평균 캔버스 그리기 6.25ms.
- 확대·이동 80프레임/1,316.7ms 관측: 평균 프레임 간격 16.67ms, P95 16.7ms. 이 환경의 짧은 측정이며 보편적 FPS 보장이 아닙니다.
- 이동 67샘플·110개 위치 모두 통행 가능한 영역에 있었습니다. 별도 경로 테스트는 모든 업무 위치 조합의 문·벽·가구 충돌을 확인합니다.
- 숨김 600ms 동안 렌더 0회와 복귀 후 재개를 검증했습니다. Headless Chrome이 탭을 계속 visible로 보고하므로 이 항목은 `document.hidden`/`visibilitychange` fixture로 검증했으며 실제 OS 탭 전환 시험과 구분합니다.
- 취소·전환 뒤 응답은 UI에 반영되지 않습니다. 다만 제공자 인터페이스가 취소 신호를 지원하지 않아 이미 시작한 로컬 모델 추론 자체는 끝까지 실행될 수 있습니다.
- 실제 외부 제공자 및 모든 언어의 번역 품질은 이번 작업에서 검증하지 않았습니다. 번역 상태·실패 복구·숫자 검증은 제어된 응답과 계약 테스트로 검증했습니다.
- 기록 완료는 현재 앱의 세션 이력 저장을 뜻하며 영구 서버 저장을 새로 추가하지 않았습니다. 스캔의 `.env.local` 경고와 Node의 기존 모듈 형식 경고는 남아 있습니다.
