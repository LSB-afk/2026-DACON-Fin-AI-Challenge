# 온톨로지 3D 네트워크

2026-09-05 · 로컬 구현 및 검증 완료. 이번 변경은 온톨로지 그래프 표현과 조작에 한정하며 기존 사무실·판정·승인·실행 출처 계약은 유지합니다. 커밋·푸시·배포·의존성 추가는 하지 않았습니다.

## 사용

[로컬 서버](http://localhost:3000) → 바로 콘솔로 → 용어·관계 사전 (온톨로지).

- 전체 지도를 기본으로 열며 실제 T-Box **99개 개념, 139개 연결**을 표시합니다. 관계 종류 48종과 화면의 연결 수 139개는 서로 다른 집계입니다. 참고 이미지의 밀도를 흉내 내기 위한 가짜 노드는 없습니다.
- 어두운 배경, 작은 역할별 노드, 가는 연결선, 유기적인 군집 배치입니다. 좌표는 실제 xyz이며 회전할 때 깊이·원근·그리기 순서가 바뀝니다. 평면 이미지의 CSS 회전이 아닙니다.
- 마우스·터치 드래그로 회전, 휠 또는 −/+로 확대·축소, ↺로 초기화, ▷로 자동 회전, ⤢로 크게 보기. Esc로 돌아옵니다.
- 노드를 누르면 기존 정의·코드 근거·들어오는/나가는 관계 패널과 연결됩니다. 검색, 역할 필터, 선택 주변 1·2단계, 실제 A-Box와 빈 상태를 유지합니다.
- Tab으로 회전 영역과 선택 노드에 진입합니다. 회전 영역의 방향키는 시점, 노드의 방향키는 개념 선택을 이동합니다. Enter로 선택, Home/End로 첫/마지막 개념을 고릅니다.
- 자동 회전은 명시적으로 켰을 때만 실행합니다. 동작 줄이기에서는 비활성화하며, 숨긴 탭은 렌더링을 멈춥니다.

## 변경 파일

- `app/_graph.tsx`: 고정 원형/역할별 평면 배치를 Canvas 3D 투영과 접근 가능한 HTML 선택 컨트롤로 교체. 확대 화면은 body portal로 분리해 앱의 애니메이션 transform에 잘리지 않도록 했습니다.
- `lib/ontology/layout3d.ts`, `layout3d.test.ts`: 재현 가능한 3D 힘 기반 배치, 중심·크기 정규화, 원근 투영. 누락된 끝점 무시, 입력 불변성, 실제 깊이 검증.
- `app/_ontology.tsx`: 전체 지도 기본값, 역할 색상과 사용 안내 정렬. 기존 실행 데이터 선택 로직은 변경하지 않았습니다.
- `scripts/verify-central-office.mjs`: 3D 조작·깊이·터치·초점·모션 검증 5개 추가. 기존 범위 선택 테스트는 새 기본값을 반영해 명시적으로 선택 주변으로 전환합니다.
- `DESIGN.md`: 디자인 스킬로 어두운 군집형 네트워크, 실제 데이터만 표시, 역할 색상·라벨 기준을 고정했습니다.
