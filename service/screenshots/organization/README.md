# AI 역할 조직도 · 검증 기록

2026-09-05. 기존 `AI 역할 분담`을 `AI 역할 조직도`로 바꾸고, 참고 이미지의 흰 배경·상단 책임 영역·업무 조율·부서별 열 구조를 페이체크의 실제 기능에 적용했다.

## 구현 범위

- 4개 부서: 상담 분석 / 금융 판정 / 검증·통제 / 답변·기록. 전체 13개 업무 기능을 사람·AI 모델·규칙 코드로 구분한다. 상단 상담사 승인과 결과 적용은 다른 책임이다.
- 등록된 판정 스킬은 급여명세서 대조와 출국 정산 2종이다. 입력 항목, 검사 규칙, 결과, 검사하지 않는 항목, 상담 예시를 각각 분리했다. 11개/5개 규칙과 2종/5종 입력은 기존 `lib/skills.ts`에서 읽으며 금융 규칙은 수정하지 않았다.
- 조직도 검색·담당 주체 필터·흐름 안내·상세 패널·스킬 이동을 제공한다. 세부 스킬로 이동하면 해당 스킬이 선택된다. 상담 시작은 예시를 준비하고 기존 입력 패널을 열 뿐, AI 요청이나 승인·적용을 자동 실행하지 않는다.
- 상태는 온톨로지와 같은 현재 case/run/inputRevision의 실제 실행 정보를 사용한다. 제공자 연결과 실행 중은 다르며, 시간은 관측된 요청 값만 표시한다. 가상 인원·대기열·성과 수치는 만들지 않았다.
- 승인 전 AI 결과의 판정·가드레일·답변·번역 링크는 현재 상담으로 연결한다. 실제 판정 화면에서 만든 결과는 해당 판정 화면으로 연결한다. 승인과 적용은 기존 공유 상태 기계를 재사용한다.
- 기존 `_views.tsx`의 정적 조직도/스킬 화면을 전용 컴포넌트로 분리했다. 새 의존성, 저장소, AI 호출 경로는 추가하지 않았다.

## 검증 명령

`service/`에서 실행한다. 브라우저 검증은 새 프로덕션 빌드를 3002 포트에서 실행한 상태를 대상으로 한다.

```sh
npm test
npm run lint
npm run typecheck
npm run verify
npm run scan
npm run build
npm run start -- --port 3002
BASE_URL=http://localhost:3002 OUTPUT_DIR=screenshots/organization node scripts/verify-central-office.mjs
node scripts/smoke.mjs http://localhost:3002
```

최종 실행 결과와 브라우저 버전은 [report.json](./report.json)에 기록한다. 조직도 전용 시나리오 11개는 3개 화면 폭, 검색과 스킬 연결, 현재 실행 상태와 수정 후 초기화, 현재 결과로의 이동, 공유 승인·적용, 미연결 상태, 스킬별 검색·입력·규칙·모바일 표시를 검증한다. 기존 상담·사무실·온톨로지 시나리오 45개도 함께 실행한다.

최종 확인: 단위 테스트 **488/488**, Chrome 브라우저 **56/56**, 골든 케이스 **32/32**, 기존 색상 토큰 대비 **33/33** 통과. ESLint·TypeScript·프로덕션 빌드·로컬 스모크 통과. 비밀/개인정보 스캔 오류 **0건**, 스캐너 자체검사 실패 **0건**. 기존 로컬 설정 경고 1건은 아래 한계에 명시했다.

독립 코드 리뷰에서 발견한 현재 AI 결과 → 빈 판정 화면 이동 오류는 먼저 실패를 재현한 뒤 수정했다. [수정 전 재현 기록](../organization-red/report.json)과 최종 보고서의 `organization-current-result-navigation`을 비교할 수 있다. 스킬 목록을 가리던 기존 도우미 안내 말풍선도 작은 도킹 버튼으로 바꾸고 세 화면 폭에서 검증했다.

## 검증 한계와 안전

- 브라우저는 통제된 응답 스트림으로 UI와 실행 경계를 검증한다. 실제 모델 추론 품질이나 외부 AI 제공자 운영 가용성을 증명하지 않는다. 로컬 스모크는 첫 화면과 제공자 상태 API 확인만 수행한다.
- 검증 대상은 설치된 Chrome과 1440×900, 1920×1080, 390×844 화면이다. Safari·Firefox·실제 모바일 기기나 스크린리더 수동 평가는 별도다.
- 비밀/개인정보 스캔의 기존 `.env.local` 경고는 무시된 로컬 설정 파일에 대한 것이다. 해당 파일은 Git에 포함하지 않는다. 스캐너는 비밀 값을 출력하지 않는다.
- 새로고침 후 상담 상태는 유지되지 않는다. 기존 세션 메모리·승인·기록 내려받기 범위를 바꾸지 않았고, 운영 배포는 수행하지 않았다.
