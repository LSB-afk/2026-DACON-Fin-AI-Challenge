# 지식 탐색기와 움직이는 사무실

2026-09-05 · 로컬 구현. 기존 변경사항을 보존했으며 커밋·푸시·배포·신규 의존성 추가는 하지 않았습니다.

## 확인할 화면

[로컬 서버](http://localhost:3000)에서 `바로 콘솔로 → AI 상담 진행`으로 진입합니다. `사무실 둘러보기`의 4번째 안내 또는 좌측 `용어·관계 사전 (온톨로지)`에서 지식 탐색기를 엽니다.

- 온톨로지: 기존 66개 개념을 **99개 개념, 관계 48종, 데이터 속성 38종**으로 확장했습니다. 개념 분류·검색, 선택 주변/전체 지도, 관계 깊이, 역할 필터, 정의·코드 근거·들어오는/나가는 관계·상속 관계·속성·공리를 한 선택으로 연결합니다.
- 실제 결과: A-Box는 현재 입력과 판정으로 구성한 스냅샷입니다. 상담 사례, 실행 UUID, 입력 버전을 구분하며, 급여명세서 편집에는 별도 버전을 표시합니다. 실행 전·필수 입력 누락·실패·새 요청 중에는 이전 결과를 현재 결과처럼 보여 주지 않습니다.
- 사무실 안내: 지금 하는 일·이유·다음 행동을 상시 표시합니다. 업무 의존 관계, 6단계 부서 투어, 4개 시점, 24개 업무·지원 공간의 이름·설명·관련 기능 연결을 제공합니다.
- 자연스러운 활동: 기존 저폴리 캐릭터가 복도·문을 통해 이동하고 자료 확인·회의·업무 동작을 합니다. 실제 AI 작업은 일상 활동보다 우선합니다. 움직임 끄기, 동작 줄이기, 숨긴 탭 정지를 지원합니다. **직원 일상 동작은 AI 실행 상태나 진행률이 아닙니다.**
- 모바일: 그래프는 선택·초점 중심으로 이름을 표시해 겹침을 줄이고, 상세 설명과 부서 조작은 읽을 수 있는 목록으로 제공합니다.

## 검증 범위와 남은 제한

- 이번 작업의 브라우저 AI 응답은 **테스트에서 제어한 응답**입니다. 새 UI의 흐름과 상태 격리를 검증했으며 실제 모델 추론이나 모든 언어의 번역 품질을 새로 검증한 것은 아닙니다. 이전 작업의 실제 모델 실행 증거와 혼동하지 않습니다.
- A-Box는 영구 이력 저장소가 아닙니다. 원문·값을 현재 화면 메모리에서 검사하며 새 저장·전송 경로를 추가하지 않았습니다. 합성 자료라는 표시는 실제 합성 자료 정의에만 적용합니다.
- 일부 T-Box 관계는 아직 A-Box 개체로 생성되지 않는 코드 계약입니다. 실제 생성 범위를 넘는 인스턴스나 판정 원인을 꾸며내지 않습니다. 공리 8종 중 코드 강제는 7종이며 미구현 상태를 표시합니다.
- 숨김 탭 검사는 headless 브라우저의 `document.hidden`/`visibilitychange` 제어 방식입니다. 실제 OS 전환·모든 기기 성능 보장이 아닙니다. 프레임 수·그리기 시간은 보고서의 해당 환경 측정값입니다.
- 캐릭터 경로 검증은 원래 바닥 좌표를 검사하고, 그 좌표가 렌더 좌표와 일치하는지 별도로 대조합니다. 문 경계에서 역투영의 부동소수점 오차가 가짜 충돌을 만들던 검사 문제를 제거했습니다.
