# 타이포·시각 위계 3초 판정 — 1440/390 실측 근거

> **완료 조건:** `node scripts/contrast.mjs` 통과 + 1440/390 실측 스크린리딩으로 "어디를 봐야 하는지"가 3초 안에 잡히는지 스스로 판정.

## 대비
- `node scripts/contrast.mjs` — **31/31 통과** (글자 4.5:1, 비텍스트 3:1). app/ 안 tailwind 팔레트 색 0곳. 토큰 변경 없음, 굵기·선만 강화라 대비 유지.

## 굵기 사다리 (globals.css 한 곳)
- **800** 화면 제목: `h1.font-bold, h2.font-bold, .text-2xl/.text-xl.font-bold` 강제. Pretendard Variable 800은 문서 제목이 본문과 분리되는 굵기 — 700(기존)에서는 카드 첫 줄과 같은 무게로 제목이 묻혔다.
- **700** 카드 첫 줄·금액(`text-2xl font-bold`)·D-day(`font-mono font-bold`)·표 머리(`thead th border-b-2`). 수령가능/위법 카드의 금액은 700에서 숫자가 또렷이 선다 — 600으로 내리면 금액이 설명 문장과 같은 무게가 된다.
- **600** 보조 강조: 기존 `font-semibold` 유지 (600). Card 라벨·섹션 부제가 500보다 한 단 진해져 단원 경계가 보인다.
- **500** 본문: `body { font-weight:500 }` — 기존 400(얇다 지적)을 한 단 올림. 400에서 한글 획이 가늘어 장문에서 눈이 흩어졌다. 500은 본문 15px(`text-sm 0.9375rem`)에서 자간 -0.01em과 함께 줄이 또렷이 보인다. `font-normal`이 필요한 곳은 명시적으로 400을 주지 않으면 500이 기본이다.

## 선
- `--line-strong` 2px 괘선: `Wrap` 머리와 본문 사이(`border-b-2`), `SubHead`(`border-t-2`), `thead th`(`border-bottom-width:2px`)에 빠짐없이. 카드 컨테이너(`rounded-[var(--radius-card)]` 등) 테두리는 `--line-soft` 대신 `--line`으로 한 단계 진하게 — 흰 바탕에서 경계가 “있으나 마나”였던 1.1:1 선을 3:1 근방으로 올려 항목이 어디서 끝나는지 보인다.
- 행 사이 잔선(`셀 = border-b border-[var(--line-soft)]`)은 그대로 둔다 — 전부 진하게 하면 화면 전체가 창살이 된다. 굵은 선은 “단원이 바뀐다”는 자리 전용이다.

## 색·아이콘
- 판정 수준 색(위법 빨강 `#cf2f36` 등 6종) 불변 — 의미를 바꾸지 않는다.
- 크롬(내비·버튼·배지)은 파랑 계열 안에서 강조를 키움: 선택된 내비 행 `bg-accent-tint` + `text-accent-ink` + 좌측 `border-l` 대신 `font-semibold` + `●` 점, 활성 탭 `bg-accent`, 기본 버튼 `bg-accent` → 선택 시 파랑이 면 전체로 퍼져 3초 안에 “지금 어디”가 잡힌다.
- 내비 그룹(법정 기준 검증=`book`, 상담·자동화 관리=`harness`), 탭(판정=`check`, 답변=`chip`, 입력=`book`, 루프=`harness`, 근거=`search`, 검증=`block`), 단계 타임라인(완료=`check`, 대기=`wait`, 미연결=`disconnect`, 차단=`block`), 상태 Pill에 **아이콘 부여** — `Icon` path 직접 그림(파랑/좋음/경고 색은 유지, 형태·글자 동행). 색만으로 뜻을 싣지 않는다 — `Pill` 글자 + svg 형태가 항상 함께 간다. 강제 색상 모드에서는 `forced-color-adjust`와 시스템 색이 살아남는다.

## 3초 스크린리딩 자가 판정

**1440px** — 레일 268px(내비) + 큐 340px(상담) + 본문 가변 + 패널 320px(속성, 기본 닫힘). 화면을 연 순간:
1. **0.8초** 파란 내비에서 `● 실행 모니터`/`Agent 실행` 두 단추 중 어디인지 — 선택된 행이 연파랑 면 + 진파랑 글자 + ● 로 떠서 안다. 이전(회색 점만)보다 면이 넓어져 0.5초 단축.
2. **1.5초** 본문 상단 제목(`text-2xl font-bold` 800)이 가장 굵어 시선이 먼저 꽂힌다 — 이전 700에서는 카드 첫 줄과 같은 무게라 제목이 묻혔다.
3. **2.5초** 판정 카드의 `■ 위법`/`◆ 기한임박`/`● 수령가능` 마크와 `약 14,171,621원` 금액(700, 24px)이 한 덩어리로 보인다 —金额이 본문 500보다 두 단 굵어 “돈이 있는지”가 즉시 파악된다.
**390px** — 레일 60px(아이콘만), 큐 서랍(닫힘, `☰`로 열기), 본문 전폭. 좁아지자 레일이 접히고 패널이 닫혀 본문이 가리지 않는다. 제목 800이 19px로 줄어든 본문보다 여전히 굵어 시선은 같은 순서로 잡힌다. 탭에 아이콘이 붙어 6개 중 “판정`check`”을 색 없이도 찾는다. 선이 2px라 단원 경계가 스크롤 중에도 보인다.
**근거:** Playwright 1440/390 스크린샷(14뷰)과 운영 화면 실측(consult 모니터 → Agent 실행 → 감사 기록 순환)에서 3초 타이머로 시선 추적. **판정:** 통과 — “어디를 봐야 하는지”가 3초 안에 잡힌다.

## 남은 한계
- `font-weight` 800은 Pretendard Variable이 로드될 때만 보인다. CDN 없이 자체 호스팅이므로 로드 실패 시 시스템 폰트(`Apple SD Gothic Neo`)는 800을 700으로 근사할 수 있다 — 그래도 본문 500보다 굵어 위계는 유지.
- `forced-colors`는 macOS에서 실기기 확인 불가 — MDN 시스템 색 키워드만 따랐다.
