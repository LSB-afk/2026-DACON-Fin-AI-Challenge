# S2 출국 정산 — 설계

- 작성일: 2026-08-20 (KST)
- 상위: `01_전략/04_스킬_구조.md`
- 스킬 DNA: 입력 → 법정 기준 대조 → 판정 + 금액 + 근거 + 다음 행동

## 1. 한 문장

> 출국하는 외국인 근로자가 **받아야 할 돈 세 갈래**를 각각 계산하고, **각각 다른 기한**을 D-day로 알려준다.

## 2. ★ 갈래가 셋이다 (둘이 아니었다)

조사 결과 하나가 더 있었다. 그리고 그게 가장 뼈아픈 것이다.

| # | 항목 | **누가 냈나** | 금액 | 신청 기한 | 시효 |
|---|---|---|---|---|---|
| ① | 출국만기보험 (퇴직금) | 사업주 | 월 임금의 8.3% × 근속 | 출국 **7일 전** | 3년 |
| ② | **귀국비용보험** | **근로자 본인** | 40~60만원 (국가군별) | 출국 **7일 전** | 3년 |
| ③ | 국민연금 반환일시금 | 본인 + 사업주 (전액 반환) | 요율 × 보수 × 근속 + 이자 | 출국 후 가능 | **5년** |
| ④ | 퇴직금 − ① 차액 | 사업주 | ①이 법정 퇴직금보다 적을 때 | — | 3년 |

**②가 핵심이다.** 귀국비용보험은 **근로자가 입국 3개월 내에 자기 돈으로 납부한 것**이다(취업교육 때 통장 자동이체). 사업주 부담인 ①과 달리 자기가 낸 돈인데, 낸 사실조차 기억 못 하는 경우가 많다. 미청구 시 3년 뒤 한국산업인력공단으로 넘어간다.

국가군별 납부액:

| 군 | 국가 | 금액 |
|---|---|---|
| 제1군 | 중국, 필리핀, 인도네시아, 태국, 베트남 | 400,000원 |
| 제2군 | 기타 (몽골 등) | 500,000원 |
| 제3군 | 스리랑카 | 600,000원 |

## 3. ★★ 국적이 분기를 결정한다 — 다만 질문이 달랐다

> **2026-08-20 정정.** 공단 원본 「외국 연금제도 조사 내용」(2025-02-01, 134개국)을 확인한 결과 이 절의 초안이 **틀렸다.** 2차 출처(언론·요약 블로그)를 근거로 썼던 내용이 원본과 배치됐다. 정정 내용을 남긴다.

### 뒤집힌 것 ① — 질문은 "받을 수 있나"가 아니라 "냈나"다

**국민연금법 제126조 제4항 제2호**: 「외국인근로자의 고용 등에 관한 법률」에 따른 외국인근로자로서 국민연금법을 적용받는 사업장에 사용된 자에게는 반환일시금을 지급한다.

즉 **E-9은 본국의 상호주의와 무관하게 반환일시금을 받는다.** 고용허가제 송출국 대부분이 사회보장협정 미체결이라 반환일시금을 못 받던 불합리를 시정하려고 2007년 개정으로 신설한 특례다.

따라서 판정할 것은 수급 자격이 아니라 **애초에 납부했는가**이다.

### 뒤집힌 것 ② — 베트남·몽골은 납부한다

공단 원본에 따르면 **베트남은 2022-01-01부터, 캄보디아는 2023-03-29부터 사업장 당연적용**이다. 몽골·라오스·키르기스스탄도 사업장 당연적용국이다. "가입 자체가 안 된다"고 썼던 것은 오류다.

### 정정된 분기

```
국적 ──┬─ 사업장 적용제외국 (21개국)              → 납부 없음 → 받을 것 없음
       │    네팔, 미얀마, 방글라데시, 파키스탄,
       │    동티모르, 말레이시아, 싱가포르, 브루나이,
       │    카자흐스탄, 남아프리카공화국, 몰디브,
       │    사우디아라비아, 아르메니아, 나이지리아,
       │    그루지야, 벨로루시, 스와질란드, 에티오피아,
       │    이란, 통가, 피지
       │
       ├─ 협정으로 면제 — 우즈베키스탄 E-9        → 납부 없음
       │    공단 원본에 "E-9 체류자격자는 협정
       │    가입증명서 제출 없이 면제"로 명시
       │
       └─ 그 외 (사업장 당연적용)                  → 납부함 → §126④2호로 수급
            베트남, 캄보디아, 인도네시아, 스리랑카,
            태국, 필리핀, 중국, 몽골, 라오스,
            키르기스스탄, 미얀마 제외 대부분
```

**설계 규율은 그대로다.** 원본 명단에 **확실히 있는 국가만 판정한다.** 없으면 `확인필요`로 내고 국민연금공단 1355로 보낸다.

### 국적별 총액 (월 215만원 · 3년 근속 가정)

| 국적 | ① 출국만기 | ② 귀국비용 | ③ 국민연금 | 합계 |
|---|---:|---:|---:|---:|
| 베트남 | 약 645만 | 40만 | 약 700만+이자 | **약 1,385만원** |
| 인도네시아 | 약 645만 | 40만 | 약 700만+이자 | **약 1,385만원** |
| 스리랑카 | 약 645만 | 60만 | 약 700만+이자 | **약 1,405만원** |
| **네팔·미얀마** | 약 645만 | 50만 | **없음 (미가입)** | **약 695만원** |
| **우즈베키스탄** | 약 645만 | 50만 | **없음 (협정 면제)** | **약 695만원** |

> 단순 산출이다. 실제는 보수월액·연도별 요율·이자에 따라 다르다. 화면에는 **범위와 면책**을 함께 낸다.

### 이 정정이 남긴 교훈

2차 출처만 믿었으면 **베트남 근로자에게 "국민연금은 없습니다"라고 말할 뻔했다.** 1인당 700만원짜리 오답이다. 상수 검증을 코딩 앞에 두는 규율이 실제로 사고를 막았다.

## 4. D-day 타임라인 — 기한이 서로 다르다

```
D-30   고용센터 출국 예정 신고
        │
D-7    ★ 보험사 청구 마감 (①②를 일괄 신청 가능)
        │   보험금신청서 + 출국예정사실확인서
        │
D-day  출국 — 공항 수령 가능
        │   ② 귀국비용: 출국 당일 공항 수령 가능
        │   ③ 국민연금: 인천공항 제1터미널 1층 입국장 A 2번 출구 옆 (09~18시)
        │
D+14   ① 출국만기보험 법정 지급 기한 (외국인고용법 §13③)
        │
D+3년  ①② 소멸시효 → 한국산업인력공단 휴면보험금
        │
D+3년  ④ 퇴직금 차액 청구권 소멸
```

**출국 후에는 난이도가 급상승한다.** 해외에서 서류를 넣어야 하고, 외국 발급 공문서는 영사확인, 사문서는 공증+영사확인이 필요하다. 그래서 D-7이 진짜 마감이다.

## 5. 입력

최소 5개. 그 이상 묻지 않는다.

| 입력 | 왜 필요한가 | S1에서 받아올 수 있나 |
|---|---|---|
| 국적 | ②의 금액, ③의 수급 가능 여부 | ❌ (스키마에서 신원 정보 제외) |
| 체류자격 | E-9·H-2만 ①② 대상 | ❌ |
| 입사일 | 근속기간 | ❌ |
| 출국예정일 | D-day 계산 | ❌ |
| 월 평균임금 | ①③④ 금액 | ✅ **S1이 계산한 값** |

**S1 → S2 연결**: 급여명세서를 이미 올렸다면 월 임금을 다시 묻지 않는다. `01_전략/02_차별화.md`에서 말한 "문서 한 장에서 답 두 개"가 여기서 실현된다.

## 6. 출력 — 판정 6종

| # | 판정 | 수준 | 내용 |
|---|---|---|---|
| S2-1 | 출국만기보험 | 수령가능 | 예상액 + D-7 기한 |
| S2-2 | 귀국비용보험 | 수령가능 | 국가군 금액 + **"본인이 납부한 돈"** 명시 |
| S2-3 | 국민연금 반환일시금 | 수령가능 / **수령불가** / 확인필요 | 국적 분기 |
| S2-4 | 퇴직금 차액 | 확인필요 | 법정 퇴직금 > ① 이면 사업주에게 별도 청구 |
| S2-5 | 근속 1년 미만 경고 | 수령불가 | **1년 미만이면 ① 일시금은 사업주에게 귀속** |
| S2-6 | 시효 경고 | 기한임박 | 이미 출국한 경우 D+3년 잔여 |

S2-5는 반드시 넣는다. 없으면 1년 못 채운 사람에게 없는 돈을 약속하게 된다.

## 7. 타입 확장 — 최소 변경

기존 `Finding`을 그대로 쓰되 두 곳만 넓힌다.

```ts
export type Level =
  | "위법" | "확인필요" | "정상"           // S1: 규범 대조
  | "수령가능" | "기한임박" | "수령불가"    // S2: 청구 판정

export type Finding = {
  // ... 기존 그대로
  deadline?: { label: string; date: string; daysLeft: number }  // ← 추가
}
```

이것만으로 결과 화면·다국어 설명·금액 집계·검증 콘솔이 전부 재사용된다. 스킬이 늘어도 UI는 늘지 않는다.

정렬 순서: `기한임박 → 위법 → 수령가능 → 확인필요 → 수령불가 → 정상`

## 9. 오탐 리스크와 방어

S1보다 위험하다. S1은 "이미 떼인 돈"을 말하지만 S2는 **"앞으로 받을 돈"**을 말한다. 액수를 부풀리면 기대를 만들고, 못 받으면 신뢰가 무너진다.

| 리스크 | 방어 |
|---|---|
| 국민연금 없는 국적에 있다고 말함 | 명단 확인된 국가만 판정, 나머지 확인필요 |
| 1년 미만인데 퇴직금 약속 | S2-5 경고 필수 |
| 금액을 확정값처럼 제시 | **범위로 표시** + "정확한 금액은 1355 / 삼성화재 02-2261-8400" |
| 이자·연도별 요율 오차 | 근사임을 명시. 공단만 개인 납부이력으로 정확 계산 가능 |

**모든 금액에 "예상"을 붙인다.** S1의 확정 표현(위법)은 S2에 쓰지 않는다.
