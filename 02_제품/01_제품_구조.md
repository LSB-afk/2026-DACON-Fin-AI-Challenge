> 급여명세서 사진 또는 출국 관련 발화 한 문장을 넣으면, 2026년 법정 기준과 대조해 **잘못 떼인 금액 / 출국 시 받을 금액과 기한**을 모국어로 알려준다.

## 2. 핵심 설계 — 추출·판정·설명의 3단 분리 (현재 실동작)

**LLM에게 판정을 시키지 않는다 — 2단은 모델 금지구역.** 이 분리는 문서가 아니라 `lib/flow.ts` 단일 출처와 `lib/rules/`→`lib/ai/` 단방향 의존으로 강제된다.

```
[입력] 발화/이미지
  │
  ├─[0단] 라우팅   모델(키워드 기준선 대 LLM 비교)  "다음 달에 돌아가요" → departure — isClarification이면 되묻기
  ├─[1단] 추출     모델(evidence 강제)  발화 → {nationality, visa, hireDate, departureDate, monthlyWage} + evidence 원문 대조
  ├─[2단] 판정     코드(순수 함수)  입력 + 2026 상수 → Finding[]  ★ 결정론적 — lib/rules만, Math.random/new Date 금지
  ├─ 가드레일     코드 G1–G8  · 온톨로지 A-Box 대조  ·  숫자 보존 검증 전 단계 차단
  └─[3단] 설명     코드 조립(narrate) + 모델 번역  Finding[] → 모국어 문장 (숫자·조문은 코드 값 그대로)
```

- **0단**: 키워드 라우터(`lib/skills.ts:routeByKeyword` 39개 트리거, baseline·폴백) + LLM 라우터(`lib/ai/agent.ts:validateRouter`, skill id 검증, evidence 필터) 병행, 불일치 시 키워드 우선. `lib/ai/agent.ts` 계약으로 테스트 20 (`agent.test.ts`).
- **1단**: `lib/ai/agent.ts:validateIntake` — 매 값마다 `evidence`가 원문 부분문자열인지, 날짜 YYYY-MM-DD, 숫자 파싱 검증. 실패는 버리고 `questions`로 되묻기(G5). vision(이미지) 추출은 로드맵·현재 픽스처로 대체, 코드는 `live:false gate:env`로 명시.
- **2단**: `lib/rules/payslip.ts`(11룰) + `lib/rules/departure.ts`(5룰, today 주입, addDays는 epoch 연산만) — 순수, 테스트 243 중 38+21건이 이 단계. 모든 금액·기한은 `lib/rules/constants-*.ts`만 본다.
- **3단**: `lib/narrate.ts` 순수 조립 + `app/api/narrate` 번역 라우트, `lib/ai/contract.ts` 숫자 보존 검증(원문 숫자 다중집합 ≠ 번역이면 502). Ollama `gemma4:latest`와 Anthropic 스위치(`lib/ai/providers.ts`, 60s/180s 시한, temperature 0).

분리가 주는 것: 환각 불가/재현 가능/단위 테스트 가능/연 1회 상수 갱신.

**3단 제약**: 설명 LLM은 2단이 준 숫자와 조문만 쓴다. 새 금액·법조문을 지어내면 계약이 던진다.

## 3. 데이터 흐름 (현재 8단계 — lib/flow.ts 단일 출처)

```
발화 입력(사람) → 0단 라우팅(모델·키워드) → 1단 추출(모델·evidence) → 2단 판정(코드·모델 금지구역)
 → 가드레일 G1–G8(코드) → 온톨로지 A-Box 대조(코드) → 답변 조립(코드) → 3단 번역(모델·숫자 보존 검증)
```

모든 화면의 루프 단계·Agent 타임라인·FlowDiagram은 `lib/flow.ts: FLOW` 8단계 배열만 읽는다. 한쪽만 고치면 `lib/flow.test.ts` 8건이 CI를 멈춘다.

개인정보: 추출 스키마에 성명·생년월일·사원번호·사업장명 없음. 이미지는 메모리에만, 응답 후 폐기. DB 없음.
